# TursiopsX — project guidance

- For any UI work in this repo (pages, sections, components), load the `tursiopsx-design` skill
  (`.claude/skills/tursiopsx-design/SKILL.md`) and reuse the tokens and components in `assets/css/main.css`.
- Static site, no build step. Keep it dependency-free and low-bandwidth (Lighthouse mobile ≥ 90).
- Copy rules from the waitlist brief: headlines in English, body in Portuguese (pt-MZ); no invented traction,
  no partner logos, no fake scarcity, synthetic demos must be labelled, keep the "advanced pre-seed" statement
  and the government-independence disclaimer.
- Operational rules (scoring, payload, emails, metrics, publication gate) live in `docs/WAITLIST-OPERATIONS.md`.
